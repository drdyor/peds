# Pediatrics LEK 2026 Audited Study Assets

This directory contains the audited review outputs and portable flashcard exports produced from the supplied Pediatrics LEK source workflow.

| File | Format | Provenance/status |
|---|---|---|
| `Pediatrics_LEK_High_Yield_Audited_Corrected_2026.pdf` | PDF | Corrected high-yield review guide with scope and errata labeling. |
| `Pediatrics_LEK_Audited_Corrected_Master_2026.docx` | DOCX | Editable audited master with charts. |
| `Pediatrics_LEK_Flashcards_2026.csv` | CSV | Portable interactive-deck export with card metadata. |
| `Pediatrics_LEK_Flashcards_2026_Anki.tsv` | TSV | Anki-compatible flashcard export. |
| `Pediatrics_LEK_Source_Drill_Summary.json` | JSON | Source-drill build summary and coverage metadata. |
| `Pediatrics_LEK_Flashcard_QA_Report.txt` | TXT | Flashcard quality-assurance report. |

The source-derived deck intentionally distinguishes verified, caveated, legacy-source, and needs-validation material. This asset bundle is for educational exam review and is not patient-specific clinical guidance. Current-sensitive doses, schedules, and protocols should be checked against authoritative current guidance before clinical use.
